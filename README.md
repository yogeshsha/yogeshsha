🧑‍💻 About Me

I'm a Flutter Developer with 3+ years of professional experience, passionate about building mobile applications that are scalable, maintainable, and enjoyable to use.

I focus on turning product ideas into production-ready applications—from crafting responsive interfaces to integrating APIs, managing complex state, and preparing releases for app stores.

- 📱 Building cross-platform apps with Flutter and Dart
- 🏗️ Applying Clean Architecture and feature-first project structures
- 🔄 Managing application state with Riverpod and Bloc
- 🔌 Integrating REST APIs and Firebase services
- 🎨 Creating responsive UIs, animations, and polished user experiences
- 🚀 Working on app deployment and Play Store / App Store releases
- ⚡ Exploring better ways to write clean, reusable, maintainable code

My philosophy: Great apps aren't just built to work. They're built to grow.
